# Button <Badge status="Stable" />

<MetaRow id="CP-01" />

사용자가 단 한 번의 클릭으로 액션을 수행하거나 선택을 내릴 수 있게 하는 핵심 인터랙션 컴포넌트입니다.
Radix UI의 `Slot` 위에 구축되어 있으며, `asChild` prop을 통해 어떤 HTML 요소도 버튼 스타일로 렌더링할 수 있습니다.
