# Sidebar Pattern <Badge status="Stable" />

<MetaRow id="PT-SB-01" />

Figma 스펙 기반 사이드바 패턴입니다. Header(로고+버전), Platform(펼침 메뉴), Projects, Footer(사용자 프로필) 구조를 따릅니다.

---

## Playground

Props를 아래 표에서 직접 조작하면 컴포넌트가 실시간으로 업데이트됩니다.

<Canvas of={SidebarPatternStories.Default} sourceState="hidden" />
<Controls of={SidebarPatternStories.Default} />

---

## 패턴 구조

| 영역 | 컴포넌트 | 설명 |
|------|----------|------|
| Header | `SidebarHeader` | 로고, 앱 이름, 버전 표시 |
| Platform | `SidebarGroup` + `Collapsible` | 펼침/접힘 메뉴 (Playground, Models 등) |
| Projects | `SidebarGroup` | 프로젝트 링크 목록 |
| Footer | `SidebarFooter` | 사용자 아바타 + 드롭다운 메뉴 |
