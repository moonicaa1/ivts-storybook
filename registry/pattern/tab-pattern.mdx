# Tab <Badge status="Stable" />

<MetaRow id="PT-TB-01" />

Inventis DS **Tab** 패턴입니다. `InventisTabsLine` 으로 **Tabs/Line 본문**(라인
탭 + Contents 슬롯)을 구성하고, DS의 **Variants · Properties · Pattern** 등은
별도 스토리로 옮겼습니다. 글로벌 헤더·레일은 **App Header** 등 다른 패턴과
조합합니다.

<TabIntroLinks />

**스토리북 사이드바 순서**는 아래 표의 **# 열**과 같습니다. **Playground**
에서만 Controls 로 `defaultValue` 를 바꿔 모든 탭·슬롯을 한 화면에서 맞출 수
있습니다.

예전 URL(`pattern-tab--tabs-line-overview-active` 등)은 **숨김 스토리**로
유지되며, 표의 **Line · Overview / Jobs** 스토리와 동일한 UI입니다.
