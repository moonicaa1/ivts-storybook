## 코드 구조

<NotificationPanelCodeStructureTable />

- **Alert Center**: `messages` + `filterAlertCenterMessages` — 탭 `Unread` 는
  `unread: true` 만 표시합니다.
- **Queue**: `queueItems` + `filterQueueItems` — 탭은 데이터의
  `queueTabKey`(`active` / `hold` / `completed`)로만 필터합니다. 카드 UI는
  **Pattern/RO Card** 의 `InventisRoCard`(`type` · `statusLabel` 등)와
  동일합니다.
- 검색 필드는 UI 트리거용입니다. 실제 필터링은 `InputGroupInput` 의 `value` /
  `onChange` 로 연결하세요.
