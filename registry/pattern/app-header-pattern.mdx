# App Header <Badge status="Stable" />

<MetaRow id="PT-HD-01" />

Inventis DS **앱 상단 헤더** 패턴입니다. Figma에 흩어져 보이는 여러 노드는 서로
다른 컴포넌트가 아니라 **동일 ❖ Header 심볼의 `Type` 프로퍼티**와 스펙/예시
라벨로 묶입니다. 구현은 `InventisAppHeader` 하나에 `variant` 로 세 가지 행을
표현합니다.

## `createOpen` (Figma 라벨)

Figma의 **`createOpen`** 노드는 별도 UI가 아니라, **Create 관련
오버레이·플로우를 연 상태**를 문서화한 라벨입니다. 앱에서는 `showCreate` 와
`onCreateClick` 으로 모달·시트·라우트 등 원하는 패턴에 연결하면 됩니다.

## 코드 구조

<AppHeaderCodeStructureTable />

- **Breadcrumb** 행: `breadcrumbs` prop (기본값은
  `defaultInventisHeaderBreadcrumbs`).
- **Window** 행: `windowTabs` + `onTabClose` · `onNewWindowClick` ·
  `onTabMenuClick`(ellipsis).
- **검색**: 데모용 트리거 버튼입니다. 실제 앱에서는 `onSearchClick` 에서 커맨드
  팔레트 등을 열면 됩니다.
