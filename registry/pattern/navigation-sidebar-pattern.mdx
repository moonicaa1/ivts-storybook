# Navigation Sidebar <Badge status="Stable" />

<MetaRow id="PT-NV-01" />

Inventis DS 앱 **네비게이션 사이드바** 패턴입니다. Figma에 나열된 여러 노드는
서로 다른 패턴이 아니라 **동일 `Sidebar`의 프로퍼티·스펙**으로 묶여 있으며, 아래
스토리는 시각적으로 **펼침 / 접힘** 두 가지만 구분합니다.

## 코드 구조

여러 Figma 노드는 **별도 패턴이 아니라** 동일 사이드바의 프로퍼티·스펙
참고용입니다. node-id 상수는 구현·검증용으로만 `navigation-sidebar/figma.ts`
(`FIGMA_NAVIGATION_SIDEBAR_NODE_IDS`)에 두었습니다.

<NavigationSidebarCodeStructureTable />

앱에서는 `model` prop으로 `defaultInventisNavigationModel`을 복사해
라벨·`href`(라우팅 시 `Link` + `asChild`로 연결)를 바꿔 쓰면 됩니다. 스토리북
캔버스는 Figma와 맞추어 **버튼**으로 렌더링합니다.
