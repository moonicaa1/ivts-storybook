# RO Card <Badge status="Stable" />

<MetaRow id="PT-RO-01" />

Inventis DS **수리·작업 오더(RO) 카드** 패턴입니다. Figma의 9개 링크는
**Variants + 문서·예시 페이지·라벨**로 묶이며, 구현 축은 **`Type=Default` ·
`Action` · `Schedule`** 세 가지입니다.

**스토리북 왼쪽 사이드바(북마크)** 에 보이는 스토리 이름·순서와 아래 표·캔버스가
**동일**합니다: `Default` → `With Action Footer` → `Schedule` → `With Progress`.

**Playground** 는 **Default** 스토리와 동일합니다 (`type="default"`, 칸반 폭
~233px).
