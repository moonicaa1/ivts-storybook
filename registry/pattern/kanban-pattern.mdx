# Kanban <Badge status="Stable" />

<MetaRow id="PT-KB-01" />

Inventis DS **칸반 열** 패턴입니다. Figma에 나열된 노드는 서로 다른 컴포넌트가
아니라 **동일 ❖ Kanban 심볼**의 **`Collapsed`** · 서브 레이어(`Kanban/Header` ·
`Kanban/Cardwrap` · `Kanban/Footer` · `Drag here`), 그리고 보드
**컨텍스트**(Minimum / Maximum / OverFlow) 예시로 묶입니다. 카드 UI는
**Pattern/RO Card** 의 `InventisRoCard`와 동일합니다.

**스토리북 왼쪽 사이드바** 스토리 이름·순서와 아래 **Variants (시각)**
표·캔버스가 동일합니다.

## Playground

Figma **Context Maximum** 고객 화면과 같은 맥락입니다: **Aside(64)** · 상단
**Header** 스텁 · **Head Wrapper**(뒤로/제목/액션 버튼) · **Filter**
(`InventisFilterBar`, **Pattern/Filter**와 동일) · **5열** 칸반, 각 열에는 **RO
카드**·**Total** 푸터·**Drag here** 가 채워져 있습니다. **카드 본문**을
드래그하면 **다른 열**(또는 같은 열의 맨 아래)로 옮길 수 있습니다
(`@dnd-kit/core`). 헤더 **⋯** 메뉴는 클릭만 되도록 분리되어 있습니다.
